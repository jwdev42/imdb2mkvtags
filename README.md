## This project is now archived

As IMDB now requires javascript to be accessed, this project will no longer be continued. I refuse to embed a javascript engine just for a small scraping tool.

## Readme

imdb2mkvtags scrapes information off the internet movie database and writes it as a xml file containing matroska tags.
